# Security Policy

## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Email: (leave a placeholder — owner will fill in)
Or open a private security advisory on GitHub: https://github.com/omiii-legitt/cortex/security/advisories/new

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

We will respond within 72 hours.

## Scope
- The live deployment at https://personal-mcp-server-taupe.vercel.app
- The source code in this repository

## Out of scope
- Vercel platform vulnerabilities (report to Vercel)
- Turso database platform vulnerabilities (report to Turso)
- Gemini API vulnerabilities (report to Google)
